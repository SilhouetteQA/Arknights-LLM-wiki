# 慈悲灯塔

**类别:** main | **模型:** deepseek-chat | **批次:** 3

## 章节摘要

本章以巴别塔的回忆开场，特蕾西娅为阿米娅讲述了一个关于小布人穿越沙漠寻找希望平原的寓言故事，隐喻了萨卡兹的苦难与追求。随后剧情转入现实，罗德岛与典范军、雇佣兵联军在夺取巨兽骸骨「生命脊椎」后，遭遇了特雷西斯启动的「阿喃那」仪式引发的红色天灾，导致骸骨失控坠落在伦蒂尼姆附近的峡谷中。联军被迫分兵三路：阿米娅、凯尔希、博士和Logos组成小队，穿越被源石活性化改造的荒原，前往食腐者军阵后方寻找并处理「提卡兹之血」以阻止「阿喃那」降临；推进之王率领典范军前往银石崖前线，寻求与公爵联军协同作战并利用诸王之息平息天灾；W、赫德雷、伊内丝等人则留守并防守瘫痪的骸骨，抵御军事委员会的反扑。

在分兵行动中，各条战线均遭遇了严峻挑战。阿米娅小队在穿越荒原时遭遇了食腐者「灵幛」的袭击，并遇到了三名逃亡的萨卡兹佣兵，其中司机玛瑞拉为保护同伴主动接纳了血魔的力量而发生异变，阿米娅拒绝处决她，展现了作为魔王的慈悲与包容。典范军方面，推进之王在吉布森镇遭遇了高多汀公爵的拉拢与威胁，她拒绝了公爵的邀请，选择留下保护平民并与食腐者交战，同时接纳了高多汀留下的感染者士兵，坚定了「典范军」为维多利亚人民而战的信念。

留守骸骨的雇佣兵战线同样危机四伏。W在调查失踪队员时，意外发现了一个赦罪师的祭坛和一座古老的萨卡兹英雄墓穴，遇到了守墓人喀利喀，并得知了特蕾西娅在此处被赦罪师复活为「祭品」的真相，这激起了W强烈的情绪波动和复仇决心。与此同时，曼弗雷德率领王庭军精锐包围了峡谷，赫德雷利用曼弗雷德不愿摧毁骸骨的心理进行拖延，但阿斯卡纶对曼弗雷德的刺杀被变形者集群识破，赫德雷本人也陷入了与曼弗雷德的正面冲突和理念交锋中。

本章还穿插了维多利亚公爵联军的动向。开斯特公爵与威灵顿公爵等组成联军，准备对食腐者占据的银石崖发起总攻，但「阿喃那」引发的天灾给联军造成了巨大打击。典范军在前往前线的途中，目睹了公爵联军内部对士兵生命的漠视，号角更是在营地中发现了曾在小丘郡背叛并杀害她队友的「同僚」，内心充满了复仇与责任的挣扎。最终，推进之王在「灰礼帽」的引导下，得知诸王之息的剑座位于开斯特公爵的旗舰上，她决定为了赢得战争而利用这一工具，率领典范军奔赴前线。

本段剧情聚焦于维多利亚战场上的三条主要战线。第一条战线是典范军与公爵联军在银石崖前线与食腐者王庭的激战。推进之王率领典范军突破源石晶簇和移动祭坛的阻碍，在开斯特公爵旗舰「荣光」号被包围的危急关头，成功激活诸王之息，劈开天灾，扭转了战局。与此同时，威灵顿公爵与爱布拉娜的塔拉军队在前线与食腐者之王孽茨雷正面交锋，但威灵顿公爵在关键时刻选择后撤，导致开斯特公爵的联军陷入被包围的险境，暴露了公爵之间深刻的矛盾。

第二条战线是阿米娅小队深入赦罪师祭坛，试图摧毁「提卡兹之血」以阻止「阿喃那」降临。小队遭遇了变形者集群和血魔大君杜卡雷残响的阻挠。Logos 独自留下对抗食腐者之王孽茨雷，以燃烧自身鲜血为代价吹响骨哨，为阿米娅争取时间。闪灵与临光（玛嘉烈）及时赶到，与奎萨图什塔展开对决，夜莺（丽兹）在关键时刻觉醒，以撕裂灵魂为代价反抗了奎萨图什塔的控制。最终，赦罪师萨卢斯以自己的血引爆了祭坛，导致「阿喃那」失控。

第三条战线是留守骸骨的雇佣兵与军事委员会的交锋。曼弗雷德率军突袭并控制了「生命脊椎」，但 W 早已设下埋伏，与阿斯卡纶联手反击。在博士等人的通讯指引下，W 成功唤醒巨兽骸骨，载着众人起飞，与从祭坛逃脱的阿米娅小队会合。众人决定利用骸骨追击特雷西斯的飞空艇，并成功登陆。在飞空艇内部，凯尔希被死魂灵困住，与特蕾西娅的意志进行了一场关于未来与源石的对话。W 则与博士和 Mon3tr 一同行动，最终在飞空艇深处遭遇了特蕾西娅的「幽灵」。

本段剧情紧接飞空艇内部战斗，W与博士、Mon3tr在飞空艇内遭遇了巴别塔的幽灵刺客和死魂灵的幻象，W在幻象中直面了自己在巴别塔陷落时的记忆。阿米娅在另一条走廊遭遇了同样来自巴别塔的幽灵，他们为守护特蕾西娅而战，阿米娅在悲伤中击败了他们。随后，众人汇合，在凯尔希的指挥下，W与阿米娅联手对抗死魂灵，最终由W拆除了飞空艇的核心。然而，死魂灵的核心并未被摧毁，反而在源石环境中自我修复，导致飞空艇失控并坠入源石内部。

在源石内部的内化宇宙中，博士陷入了与普瑞赛斯相关的深层幻境，回忆起了关于源石创造和宇宙终结的片段。凯尔希、阿米娅和W等人也各自经历了由源石根据他们潜意识构建的幻景。众人最终在源石海中的一艘罗德岛幻影上汇合，并发现萨卡兹的众魂正在此行军，而他们的目的地是源石海中央的巴别塔。在Logos的掩护下，众人登上巴别塔，直面了特蕾西娅。

特蕾西娅揭示了她的计划：她已成功进入源石内部，并试图控制源石以彻底改变萨卡兹的命运，创造一个不受天灾和矿石病侵扰的家园。阿米娅和W试图说服她，但特蕾西娅认为她们是萨卡兹的敌人，双方爆发战斗。在战斗中，阿米娅通过黑冠与特蕾西娅的回忆相连，理解了她的痛苦与决心。最终，特蕾西娅将自己的力量与意志传承给阿米娅，并选择彻底消散于源石中，为萨卡兹带来真正的自由。

特蕾西娅消散后，众魂也随之离去，源石内部开始崩溃。众人乘坐飞空艇残骸迫降在伦蒂尼姆。战场上，萨卡兹的攻势因特蕾西娅的离去而受挫，维多利亚联军抓住机会反攻。然而，威灵顿公爵突然背叛，宣布塔拉独立，并与爱布拉娜的军队一同转向，使战局变得更加复杂。在伦蒂尼姆城内，整合运动在塔露拉和九的领导下开始行动，分发物资并组织民众。凯尔希与博士讨论着特蕾西娅留下的‘最初的源石’和未来的挑战，而特雷西斯则在飞空艇上独自悼念特蕾西娅，并誓言要继续她的道路。

## 概念列表

### 食腐者的巫术/传统

- **行号范围:** [723, 741]
- **讨论摘要:** 凯尔希解释食腐者吞噬生命滋养肉体，强大的食腐者会用身体给养弱小的同胞，换来速度和力量，构成死与生的循环。Logos补充被其巫术捕获会流失生命力。
- **实质讨论:** True

### 诸王之息

- **行号范围:** [2164, 2219]
- **讨论摘要:** 「灰礼帽」讲述诸王之息的起源：来自萨尔贡南方的秘宝，能抑制源石结晶扩散，后被铸成剑形作为王权象征。其剑座是开斯特家族研究的产物，能最大化利用其力量。

凯尔希向博士解释诸王之息的本质，指出它并非传说中的神器，而是一件古老的城防装置，能抵消源石反应，但无法完全停止源石活动。
- **实质讨论:** True

### 源石的同化本质

- **行号范围:** [2437, 2445]
- **讨论摘要:** 凯尔希详细解释了在「阿喃那」作用下，源石会加速与所有生灵和死物结合，以同化形式封存信息，导致个体瞬间「分解」为源石粉尘。
- **实质讨论:** True

### 变形者集群的本质与存在

- **行号范围:** [2554, 2596]
- **讨论摘要:** 变形者集群与凯尔希进行了一场关于存在本质的哲学对话。变形者集群描述了它们因最初的提卡兹魔王触碰源石而「醒来」并获得思考能力的过程，并探讨了凯尔希作为「不灭之人」的自我认知，质疑记忆和职责是否能定义一个人的连续性。
- **实质讨论:** True

### 战争的循环与萨卡兹的命运

- **行号范围:** [2743, 2752]
- **讨论摘要:** 凯尔希描述了万年前萨卡兹通过源石获得巫术并唤醒「阿喃那」后，风暴笼罩大地、源石几乎吞噬一切的历史，指出战争只是暂时的停歇，循环永无止境。
- **实质讨论:** True

### 魔王的力量与本质

- **行号范围:** [2670, 2671]
- **讨论摘要:** 凯尔希指出「魔王」是中性的力量，其作用是推动还是阻止灾厄取决于使用者，而奎萨图什塔想要的是通过触碰流传万年的秘密，从原点中寻求更大的力量。
- **实质讨论:** True

### 赦罪师的血脉与永生

- **讨论摘要:** 奎萨图什塔向闪灵阐述赦罪师的理念，认为爱与恨、生与死本是一体，一代代赦罪师的灵魂通过仪式连接流传，在死亡与新生中荡涤杂质，接近最初的完美个体。
- **实质讨论:** True
