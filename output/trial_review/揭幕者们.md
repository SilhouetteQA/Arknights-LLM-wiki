# 揭幕者们

**类别:** side | **模型:** deepseek-chat | **批次:** 3

## 章节摘要

本章围绕新沃尔西尼建城一周年庆典前夕展开，多条剧情线并行推进。代理市长莱昂图索积极筹备狂欢节巡游，试图通过正式就任市长来巩固新政，但遭到拉维妮娅的担忧与反对。莱昂图索在赴约途中遭遇车祸重伤昏迷，拉维妮娅与警察展开调查，发现肇事车辆与威尼斯载具公司有关，卡车司机索默尔承认自己就是肇事者，并供出互助会内部存在为家族偷运违禁品的网络。与此同时，卡车互助会领袖伊雷妮在得知真相后，试图通过向萨卢佐家族家主阿尔贝托交出证据来换取互助会的安全，但阿尔贝托提出了更苛刻的条件。

Scene 1中，英格丽告知翁贝托卢奇诺被威尼斯家族带走，翁贝托决定独自前往营救，英格丽坚持同行。两人抵达威尼斯宅邸后，发现老威尼斯已找到卢奇诺并带在身边。翁贝托与老威尼斯重逢，揭露自己曾是瓦古的「剪裁师」，为老威尼斯执行暗杀任务。翁贝托以量体裁衣为由，请求老威尼斯放过卢奇诺，老威尼斯同意。安东尼奥与英格丽在外对峙，安东尼奥坚持不放卢奇诺，英格丽以刀相逼，老威尼斯出面制止。

Scene 2通过闪回揭示英格丽的过去：她幼年被老威尼斯收养，后因女儿丽萨被刺杀而离开家族。老威尼斯试图挽留，但英格丽决心复仇，归还家徽。安东尼奥透露已查清丽萨受伤的真相，但拒绝告知英格丽。老威尼斯警告安东尼奥不要打扰翁贝托。家族成员报告港口花车被烧，伊雷妮被带走调查。

Scene 3-4中，柳德米拉（弑君者）在乌萨斯解散整合运动残余成员后返回叙拉古，寻找老师。她发现老师已被红杀死，开始追踪红复仇。红在梦中与「外婆」对话，确认猎狼使命。柳德米拉被索默尔救起，加入卡车互助会。四个月后，柳德米拉发现索默尔为威尼斯家族走私货物，决定陪他完成最后一趟。

Scene 5-6中，柳德米拉与索默尔在运输途中遭遇红和子月的袭击，车辆失控。柳德米拉追击红，索默尔失踪。柳德米拉返回营地，得知自己已通过市民身份审核。她寻找索默尔，发现卡车被藏在港口花车中，车厢内藏有大量武器。柳德米拉放火烧毁花车以销毁证据。

Scene 7-8中，拉普兰德与扎罗旁观城市各方势力。拉普兰德报警后，德克萨斯与拉维妮娅调查车祸。拉普兰德带德克萨斯观看港口火灾现场。伊雷妮因纵火嫌疑受审，阿尔贝托和安东尼奥出庭作证，提供不在场证明，伊雷妮被无罪释放。索默尔被家族成员带走后失踪。

Scene 9-10中，拉维妮娅意识到庭审是家族操控的结果，决定主动出击。她以资质审查为由拘留阿尔贝托，同时搜查威尼斯工厂。安东尼奥与老威尼斯摊牌，揭露自己曾是玻利瓦尔军人，决心夺取权力。伊雷妮收集证据，决定联合卡车互助会保护自己，并暗中保护拉维妮娅。柳德米拉承诺防止伊雷妮越过底线。

Scene 1中，狂欢节前夕，大帝和大祭司帮助诺埃米修复受损花车，诺埃米讲述了自己因家族保护费而放弃披萨店梦想、成为警察的经历。翁贝托与英格丽告别，英格丽已得知女儿丽萨受伤的真相，准备复仇。港口调度台被威尼斯家族成员渗透，甘比诺与同伙计划关闭移动城市定位系统，迎接家族陆行舰以控制新沃尔西尼。拉普兰德突然出现，识破计划但未阻止，反而要求甘比诺去取卢奇诺的礼盒。

Scene 2中，多利、大帝和大祭司在狂欢节人群中讨论叙拉古传说。莱昂图索从昏迷中醒来，坚持要参加狂欢节演说，德米特里护送他并试图摊牌。红在梦境中与外婆对话，确认最后的真狼是裁缝翁贝托。柳德米拉发现红的身影但克制住复仇冲动，选择留在卡车互助会。安东尼奥在隐蔽据点指挥威尼斯家族的行动，计划在巡游队伍到达法院广场时控制行政大楼。卡彭执行命令，家族成员开始清理广场守卫。拉维妮娅和德克萨斯在法院准备应对变数，伊雷妮率卡车司机包围法院，声称要保护拉维妮娅。

Scene 3中，伊雷妮向拉维妮娅提交家族渗透名单，要求启动紧急审判程序，拉维妮娅质疑其动机。德米特里与莱昂图索对峙，揭露贝洛内家族成员对莱昂图索的失望和敌意。拉普兰德劫持威尼斯家族的陆行舰，将武器散落在广场上，迫使家族成员和卡车司机对峙。安东尼奥前往港口时被卡彭背叛，英格丽出现准备复仇。狼之主们在甲板上观察局势，扎罗说服其他狼之主观看拉普兰德的游戏。卢奇诺潜入陆行舰试图炸毁武器，与甘比诺对峙，甘比诺讲述了自己的西西里人身份认同。

Scene 4中，瓦古向卢奇诺揭露翁贝托作为獠牙的过去，以及他因抚养卢奇诺而一再推迟履行承诺。红找到翁贝托，翁贝托坦然面对死亡，完成了最后一套套装。德克萨斯与拉普兰德在陆行舰甲板上对话，拉普兰德解释自己帮助揭露阴谋的动机，并打赌谁会先动手。英格丽与安东尼奥对峙，揭露安东尼奥当年为夺权而策划伤害丽萨的真相，英格丽重伤安东尼奥。家族成员准备强攻法院，伊雷妮谎称拉维妮娅已签署判决书，命令司机们拿起武器。

Scene 5中，一声神秘的铳响阻止了冲突爆发，巡游队伍到达广场。伊雷妮提议双方放下武器，共同迎接巡游队伍。重伤的安东尼奥被老威尼斯派来的成员处决，老威尼斯准备与市政厅谈判。子月被红设伏杀死，红在胜利后得知外婆的真相——外婆欺骗了她，红既是猎狼人也是真狼。拉普兰德与德克萨斯在甲板上完成压轴演出，拉普兰德发表对叙拉古泥潭本质的见解，德克萨斯承认自己曾是理想主义者。莱昂图索到达广场发表演说，强调新沃尔西尼的法治和未来。德米特里承诺贝洛内家族将以合法方式进入城市。

Scene 6中，红因真相崩溃，柳德米拉找到她并决定带她去罗德岛见凯尔希。拉普兰德探视被拘留的阿尔贝托，告知萨卢佐家族产业已被德米特里接管。卡彭和甘比诺清理街道，讨论老威尼斯的切割策略，计划开出租车公司。英格丽向拉维妮娅告别，拉维妮娅发布通缉令但允许她离开。伊雷妮向莱昂图索提交辞呈被拒，莱昂图索邀请卡车工会纳入市政系统。柳德米拉向伊雷妮告别，警告她不要被权力腐蚀。拉普兰德拒绝带狼之主离开叙拉古，反而成为狼之主的头狼，准备参与新的游戏。德克萨斯和乔万娜加入新沃尔西尼作为物流顾问。阿格尼尔神父与莱昂图索会面，透露西西里夫人并未出手干预。翁贝托在裁缝店等待死亡，与阿格尼尔神父重逢。

## 概念列表

### 剪裁师

- **行号范围:** [1710, 1713]
- **讨论摘要:** 老威尼斯回忆翁贝托作为「剪裁师」的过去，指出他通过裁缝订单暗杀目标，令蒙特卢佩的家族忌惮。
- **实质讨论:** True

### 家徽

- **行号范围:** [1852, 1854]
- **讨论摘要:** 老威尼斯向幼年英格丽解释家徽的意义：接下它意味着成为一家人，家族联系比血缘更紧密。
- **实质讨论:** True

### 游戏（狼之游戏）

- **行号范围:** [2135, 2141]
- **讨论摘要:** 红在梦中与外婆对话，外婆解释狼的游戏规则：伤害外婆是狼的游戏，对红来说游戏的规则便是杀死他们。
- **实质讨论:** True

### 试验场

- **行号范围:** [3150, 3155]
- **讨论摘要:** 安东尼奥回忆莱昂图索对新沃尔西尼的描述：西西里夫人将城市作为试验场，用新秩序管理旧人，必然有人被吞没。安东尼奥认为这轻率得像贵族随手画圈。
- **实质讨论:** True

### 狂欢节

- **行号范围:** [3257, 3258]
- **讨论摘要:** 诺埃米解释狼在叙拉古传说中有特殊意义，花车数量和原型不能少，否则会引起恐慌。
- **实质讨论:** True

### 獠牙/真狼

- **行号范围:** [3971, 4065]
- **讨论摘要:** 瓦古向卢奇诺解释獠牙与狼之主的关系：獠牙是被狼之主选中的人类，无法拒绝；翁贝托提出条件要求先抚养幼崽，瓦古同意但最终因翁贝托的拖延而失败。

红质问翁贝托为什么进行残忍的游戏，翁贝托回答自己是被命运稀里糊涂找上的人，并反问红杀死所有真狼后要去哪里、做什么。
- **实质讨论:** True

### 体面

- **行号范围:** [4163, 4171]
- **讨论摘要:** 安东尼奥质疑威尼斯家族的体面，指出家族也只是一群手上沾满血的混蛋，翁贝托摆脱家族做套装、英格丽脸上的伤疤都证明体面是虚伪的。
- **实质讨论:** True

### 叙拉古的泥潭

- **行号范围:** [4381, 4386]
- **讨论摘要:** 拉普兰德向德克萨斯阐述叙拉古的本质：泥潭能将所有人变成恶狼，将一切新地盘变成一模一样的泥潭，最好的方式是学会在里面游泳而非逃离或改造。
- **实质讨论:** True
