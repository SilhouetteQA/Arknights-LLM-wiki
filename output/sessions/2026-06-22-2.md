# 会话总结 — 2026-06-22-2 (大地巡旅 OCR 完成)

## 任务

处理《大地巡旅》403 张扫描图片，使用 MiniMax M3 视觉 API 做 OCR 提取为 Markdown。

## 关键决策

### 模型与参数
- **MiniMax M3 原生多模态**：`MiniMax-M3` 支持图片输入（MiniMax-M1 不支持图片，已验证）
- **禁用 thinking 模式**：`extra_body={"thinking": {"type": "disabled"}}`，输出 token 从 2000 降至 500-600（省 70%），且无质量下降
- **重试逻辑**：内置 3 次重试（2s/4s/8s 指数退避），解决 Connection error
- **中文 vs 英文提示词**：中文提示词在内容审查场景下成功率更高（page 376 用学术中文恢复）

### 质量设计
- **图片描述**：`[图：...]` 标记，自动提取插图内容
- **手写批注**：`【手写批注：...】` 标记凯尔希批注
- **模糊文字**：`[推测：X]` 标注不确定字符，不做硬猜测
- **边栏/页码**：保留为 `[注：...]` 格式

### 工程决策
- **续跑机制**：JSON state 文件记录每页状态（completed/failed），中断不丢进度
- **Windows GBK**：`sys.stdout` 包装为 UTF-8、`RMB` 替换 `¥` 避免编码崩溃
- **统一定价**：MiniMax M3 标准版 ¥2.1/M in + ¥8.4/M out，real-time 计算
