## 关键决策

### 1. 美学方向: PRTS 终端 (Retro-Futuristic Terminal)
模拟游戏内 PRTS 系统界面。用户从 4 个方向中选择 D（PRTS Terminal），后又调整为 C 配色（罗德岛靛蓝 + 源石琥珀）+ 2/4/5 效果（glow/borders/cursor）。

### 2. 字体: Share Tech Mono (标题) + Source Code Pro (正文)
统一等宽体系，工业感最强，类 PRTS 原生界面。

### 3. 配色: 10 个 CSS 变量
--bg-root #080c14 / --bg-panel #0d1525 / --bg-input #060a12
--accent-blue #4fc3f7 / --accent-amber #ffb000 / --accent-gold #e6b422
--text-primary #c8d6e5 / --text-secondary #5a6a80 / --border-dim #1a2740

### 4. 效果: glow + 角标 + 自定义光标
- 文字发光: text-shadow on 标题/系统状态/步骤标签
- 角标: ::before 伪元素四角 L 形装饰线
- 光标: caret-color: amber; cursor: crosshair

### 5. 双栏布局: 对话 (flex:1) + 检索追踪 (280px)
5 种 SSE 事件完整映射到 UI: route → 路由信息条 + 步骤卡片, token → 流式追加, step → 步骤卡片滑入, sources → 来源清单, done → 状态栏更新

### 6. 无需框架
保持 native HTML/CSS/JS — 与项目技术栈一致（README 约定 "原生 HTML+CSS+JS, CSS/JS 从单文件拆分为独立文件"）
