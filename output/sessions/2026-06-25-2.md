# 会话总结 — 2026-06-25-2 (Agent 五维评估器实施)

## 任务

吸收 mrfz 项目 QA 模式，构建 100 题测试集 + MiniMax M3 LLM-as-judge 五维评估器，全量跑出评估基线。

## 关键决策

### 1. 评估器架构
- 五维：entity_link_precision / source_relevance / answer_accuracy / answer_focus / routing_correctness
- **MiniMax M3 做 judge**（用户明确要求），与 agent DeepSeek 解耦
- `thinking: disabled` + 多种输出格式解析 `(A)` `{A}` `A`

### 2. 100 题测试集
吸收 `batch_qa.py` (165题/13类) + `qa_log.json` (15条真实用户查询)：
- 14 类别 / 5 维 / 3 难度 / 7 意图 / simple(43) + complex(57) 路由

### 3. 路由器修复
`_infer_intent_local` 优先级调整：chapter_summary + character_profile → concept_definition
修复后意图 25/25 (100%)，路由 23/25 (92%)

### 4. 评估方法论缺陷发现
MiniMax M3 judge 只能看 agent 检索来源，不能访问完整知识库。
案例 q063 "罗德岛精英干员"：Sharp 真实存在于 `factions/罗德岛.md`，agent 检索未命中 → 判 D（误判为幻觉）
**结论**：answer_accuracy (1.36) 混入了检索失败 + 真实幻觉
