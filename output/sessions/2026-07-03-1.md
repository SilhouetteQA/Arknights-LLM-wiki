# 会话总结 — 2026-07-03-1 (检索质量全面修复 + 前端重设计)

## 任务

本会话发现并修复了 Agent 系统的多个关键缺陷，涉及数据加载、检索策略、流式体验、前端 UI 四个层面。

## 修复清单

### 数据加载 Bug（3 个静默失效）

1. **`_load_operators` 结构错误**: operators.json 结构为 `{fetched_at, total, operators: [{name_zh, ...}]}`，原代码遍历顶层 key 永远只拿到 4 个字段名。修复后正确读取 420 个干员名。
2. **`_load_identity_map` 结构错误**: identity_map.json 结构为 `{_description, mappings: {alias: canonical}}`，原代码遍历顶层 key 只拿到 4 个元数据。修复后正确读取 137 条映射。
3. **NPC 无法匹配**: 新增 `_load_character_names()` 从 `v2_characters/*.json` 文件名提取 642 个角色名（干员+NPC）。

结果：实体提取从 0-4 个实体 → 覆盖 identity_map(137) + operators(420) + characters(642) + chapters(109)。

### 意图校验

4. **LLM 意图幻觉**: `_llm_intent_rewrite` 返回 "worldview"（非 7 种有效意图之一），导致下游无检索策略。添加 `VALID_INTENTS` 校验，无效时回退本地意图。

### 检索质量 — 核心修复

5. **角色查询跨章均匀采样**: 原 `event_store.search(entity="阿米娅", limit=3)` 只取 3 个随机事件（32 章出场 → 漏掉维多利亚、乌萨斯等时期）。新增 `_sample_events_across_arc()`：
   - 从 entity_source_map 获取全部出场章节
   - 按时间线排序
   - 均匀选取 5 个代表性章节（0%/25%/50%/75%/100%）
   - 每章取 2-3 个事件 → ~12 个时间分布的事件
6. **非角色查询 limit 提升**: 3 → 6
7. **Agent 提示词更新**: 角色检索新增 5 步流程指引

### 流式体验

8. **SSE 事件不刷新**: `yield` 后紧跟同步阻塞调用，事件循环无法发送数据。每个 `yield` 后加 `await asyncio.sleep(0)` 强制刷新。
9. **simple_search 阻塞事件循环**: 改为 `loop.run_in_executor` + `queue.Queue` 实时推送检索进度。
10. **token 一次性到达**: 块间加 15ms 延迟模拟逐字流式。

### 前端重设计

11. **配色**: 冷蓝+琥珀 PRTS 终端 → "Noir Archive" 暗暖色系（古铜金 `#d4b56a` + 奶油白 `#f0ebe1`）
12. **字体**: 13px mono → 15px 系统无衬线，行高 1.85
13. **光标**: 移除全局 crosshair，按钮/输入框/正文各用合适指针
14. **文本可读性**: textContent → innerHTML，支持段落 `<p>`、粗体 `<strong>`、标题、分隔线
15. **新增功能**: 智能滚动（上滑不拽回）、流式闪烁光标 `|`、hover 复制按钮、Shift+Enter 换行

### 清理

16. 删除 `arknights_wiki/eval/` 全部评估器文件
17. 删除 server.py 中 QA 日志功能（`_log_and_stream`）
