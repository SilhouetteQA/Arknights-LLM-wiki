## 关键决策

### 视频定位
- **C 方案**：分类处理 — 特别映像作为补充上下文，探泰拉系列作为独立提取源
- 视频 = 高信息密度锚点，原文 = 覆盖更广但碎片化
- 视频给结构，原文填细节

### 提取方法论：B+ 方案（视频种子 + 原文双通道）
```
通道 1: 视频种子提取 → 结构化种子库（概念/阵营/地点定义+分类+关系）
通道 2: 逐章原文重提取 → 实体链接到种子库 + 发现新实体
通道 3: 跨章聚合 → 去重合并 → Wiki 页面
```

### 概念分类体系（6 子类）
| 子类 | 示例 |
|------|------|
| 自然现象/物质 | 源石、天灾、A类矿石病 |
| 种族/血脈 | 萨卡兹、提卡兹、阿戈尔 |
| 超自然存在 | 巨兽、兽主、海嗣、邪魔 |
| 技术/技艺体系 | 源石技艺七学派、移动城市 |
| 社会制度/文化 | 拉特兰律法、骑士竞技 |
| 特殊地域/异域 | 焚风热土、黑流树海、荒域 |

- **纳入标准**：属于六子类之一的客观世界实体
- **排除标准**：情感/品德/角色观点/模糊隐喻（通过分类体系自动拦截）
- **不设频率门槛**：单次出现的关键信息（如崔林特尔梅之金巫王荒域对话）保留，标注 `coverage: single` 供人工审查

### 三层关系
- 概念层：定义世界规则（"世界是什么"）
- 阵营层：有组织的行动者（"谁在行动"）
- 地点层：具体物理场所（"发生在那"）
- 交叉实体（如"萨卡兹"）：概念层提取种族本质，阵营层提取王庭作为政治军事组织
