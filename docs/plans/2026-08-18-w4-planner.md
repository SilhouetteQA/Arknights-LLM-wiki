## 关键实现细节

1. **TaskNode**：TypedDict（id/description/tool/args/depends_on/status/result）
2. **规则模板**：按 question_type 生成任务列表（comparison/list_enumeration/causal_reasoning/chapter_summary/其他），
   工具参数从 route.entities 推导（如 comparison → 逐实体 get_entity_page + search_events(entity)）
3. **LLM 规划**：`plan_tasks` 内部用 `chat_completion`（统一入口，重试+trace 自动）；
   prompt 输出 JSON 数组；校验：工具 ∈ TOOL_EXECUTORS、任务 ≤6、depends_on 引用存在、无环；
   任一不通过 → 规则模板兜底（source="rule"）
4. **执行器**：拓扑排序（Kahn）+ 串行执行；任务失败不中断（status=failed，聚合时跳过）；
   执行复用 `graph._execute_tool_traced`（tool_call span + W2 stats）
5. **graph**：`build_planner_graph()` = plan_node → execute_node → synthesize_node（复用现有 synthesize）；
   `AgentState` 加 `tasks` 字段（可选）；server complex 分支按 `ARKNIGHTS_AGENT_MODE`（默认 planner）
6. **trace**：plan_node span name="planner"、metadata node_type=NODE_TYPE_PLANNER/n_tasks/source
7. **评测**：`ARKNIGHTS_AGENT_MODE=planner python -m arknights_wiki.eval.runner --bench ... --limit 10 --out output/eval/w4_planner`
   对比 w2_regression(0.936)/w3_mcp(0.967)；用户自测题记录 scripts/planner_demo.py 输出
