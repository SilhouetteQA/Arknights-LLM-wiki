## 三、新发现，待修复 (6 项)

### 11. 关键对话场景被严重压缩（高优先级）

**现象**: 辞岁行天镜阁 53 行兄弟重逢对话 → LLM 压缩为 1 行"炎武与真龙回顾四十年恩怨"

**根因**: 同 batch 内大量世界观事件（岁兽/不反/字伥/太尉阴谋）竞争 token 预算，LLM 判断对话"信息密度"低于设定揭示

**修复**:
- ✅ 已添加 prompt §4 "关键对话场景识别" — 判别标准 + 高优先级 + 120-200 字要求 + 3 处引用
- 待重跑验证

### 12. 炎武 = 魏彦吾 身份链接断裂（高优先级）

**现象**: 炎武（皇子）有 alias "魏彦吾"，但 LLM 未从原文中自动发现这个链接。原文胞妹对话明确说了"去往龙门"，"伪·炎武"的命名逻辑也未捕捉

**根因**: 跨章身份链接超出单章 LLM 能力；同一章内如果对话出现在末尾 batch，可能被压缩

**修复方向**:
- entity_checklist 中为炎武（皇子）标注 aliases + known_identities
- 在"关键对话场景"规则中加入"身份揭示"识别指引

### 13. 陈晖洁 = 炎景公主之女 未链接（中优先级）

**现象**: 辞岁行陈昭芊在天镜阁揭露陈晖洁皇亲国戚身份、陈家因炎景公主病逝遭牵连，但未建立：炎景公主 = 胞妹 = 为兄弟调解而死 = 陈晖洁母亲

**根因**: 人物血缘关系属于关系图谱层面，超出了当前实体-事件链接的范围

**修复方向**: 在 entity_checklist 中补充已知人物关系（如炎景公主 aliases: ["胞妹", "陈晖洁之母"]），由 LLM 在事件中自然关联

### 14. 天机阁/天师府等组织仍 0 members（中优先级）

**现象**: 天机阁 5 条事件但 member_composition 为空

**根因**: LLM 描述了天师作为群体的行动，但没有将具体的"老天师""麟青砚""白定山""苍霆伯"等个体映射到 member_composition 字段

**修复方向**: prompt 中增加"制度性角色 → 同时记录 member_composition"的强制要求

### 15. 常规战斗场景的事件稀释（低优先级）

**现象**: 部分 entity 的 story_events 中包含大量"minor: XX在战斗中使用源石技艺"类事件，信息量低

**根因**: Pass 1 已经覆盖了战斗事件，Phase 3 不需要重复

**修复方向**: prompt 明确"常规战斗中实体作为工具/背景出现，不单独记录；仅当战斗揭示了实体的新信息时才记录"

### 16. 取江峰/取江峰（攥江峰）未合并（低优先级）

**现象**: 同一地点因名字变体未合并

**修复**: 手动合并

## 四、架构层面的局限性

| 局限 | 影响 | 缓解措施 |
|------|------|----------|
| 单章处理无跨章记忆 | 多章人物弧线断裂、身份链接需手动 | entity_checklist 预标注 aliases + known_instances |
| DeepSeek 8192 tok_out 上限 | 事件密集的章会压缩关键场景 | 分批阈值降低 + 关键场景优先输出 |
| 关系图谱不在 Phase 3 范围 | 父子/兄弟/师徒/君臣等关系未结构化 | 通过 member_composition + aliases 间接表达 |
| 角色 vs 世界观实体的边界模糊 | 颉/重岳等边界 case 需手工标注 | ABC 分类规则 + entity_checklist 预标注 |
